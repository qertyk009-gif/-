# Барахолка24 — симулятор перекупщика

Мобильная игра для Android на Godot 4.3 (GDScript). Пародия на доску
объявлений: игрок ищет товары в ленте, торгуется с ботами-продавцами,
покупает, при необходимости ремонтирует, выставляет на продажу и
торгуется с ботами-покупателями.

Полностью офлайн: никакого интернета, никаких платных API, никакой
рекламы и доната. Все диалоги ботов генерируются локально по шаблонам.

## Основной игровой цикл

1. **Лента** — листаем объявления, фильтруем по категории.
2. **Торг** — открываем чат с ботом-продавцом, торгуемся (готовые реплики
   или своя цена), иногда ловим мошенников.
3. **Покупка** — сделка заключена, товар попадает в инвентарь.
4. **Ремонт** — осматриваем предмет в 3D, диагностируем дефекты, покупаем
   запчасти у ботов, проходим мини-игры ремонта.
5. **Продажа** — выставляем объявление, торгуемся с ботом-покупателем,
   получаем деньги за вычетом комиссии площадки.
6. Повторяем, прокачивая навыки (торг/ремонт/оценка/антифрод) и выполняя
   ежедневные задания.

## Технические особенности

- **Движок**: Godot 4.3, GDScript, рендерер Mobile.
- **Платформа**: Android 8+, только `arm64-v8a`, цель — APK ≤ 60 МБ.
- **3D**: только low-poly примитивы, собранные прямо в коде
  (`scripts/models/ProceduralModel.gd`), без внешних бинарных моделей,
  без теней в реальном времени. 3D используется только в окне осмотра/
  ремонта — весь остальной интерфейс на Control-нодах.
- **Данные**: товары, дефекты, запчасти, характеры ботов, фразы —
  в `data/*.json`, а не захардкожены в коде.
- **Сохранения**: локально в `user://save_game.json`, автосохранение
  после ключевых действий.
- **Торг**: детерминированные формулы на основе настроения/терпения/
  жадности/честности бота — см. подробные комментарии в
  `scripts/autoload/NegotiationEngine.gd`.
- **LLM-точка расширения**: `scripts/autoload/LLMBridge.gd` — отключена
  по умолчанию (`enabled = false`), API-ключи никогда не хранятся в
  репозитории/APK.

## Структура проекта

```
barahlo24/
├── project.godot              # конфигурация проекта, autoload-синглтоны
├── export_presets.cfg         # пресет экспорта Android (arm64-v8a)
├── data/                      # JSON-данные: товары, дефекты, запчасти...
├── scripts/
│   ├── autoload/               # GameData, GameState, SaveSystem,
│   │                           # NegotiationEngine, BotFactory, MarketSim,
│   │                           # ThemeManager, LLMBridge
│   ├── bots/DialogueGenerator.gd
│   ├── data/ListingGenerator.gd
│   ├── models/ProceduralModel.gd
│   ├── repair/                 # 4 мини-игры ремонта + фабрика
│   └── ui/                     # вкладки: лента, инвентарь, мастерская,
│                                # профиль, чат торга, карточка объявления
├── scenes/
│   ├── ui/                      # BootSplash.tscn, MainHub.tscn
│   └── 3d/ItemInspector3D.gd    # окно 3D-осмотра/ремонта
├── assets/icon/                 # icon.svg + icon_generator.py + PNG
└── .github/workflows/build-apk.yml
```

## Сборка APK

Сборка полностью автоматическая через GitHub Actions — ничего
устанавливать на свой компьютер не нужно. Подробная инструкция для
новичка — в [BUILD.md](BUILD.md).

## Что реализовано

- Лента объявлений с пулом карточек и ленивой подгрузкой.
- Офлайн-торг с математической моделью (настроение/терпение/жадность/
  честность), мошенники с фейковой предоплатой.
- Ремонт: диагностика, покупка запчастей разного качества, 4 мини-игры
  (отвёртка, замена детали, чистка, пайка).
- Инвентарь, объявления на продажу, комиссия площадки, репутация.
- Навыки с прокачкой (торг/ремонт/оценка/антифрод), ежедневные задания,
  рыночные события (спрос/дефицит по категориям).
- Тёмная/светлая тема, простая заставка, процедурная иконка приложения.
- Автоматическая сборка и публикация debug-APK через GitHub Actions.
