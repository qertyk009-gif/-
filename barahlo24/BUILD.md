# Как собрать APK — инструкция для новичка

Эта инструкция не требует установки Godot, Android Studio или чего-либо
ещё на ваш компьютер. Вся сборка происходит на серверах GitHub.

## Шаг 1. Создайте аккаунт на GitHub

Если у вас уже есть аккаунт на [github.com](https://github.com) —
переходите к шагу 2.

1. Откройте https://github.com/join
2. Заполните имя, email, пароль и завершите регистрацию.

## Шаг 2. Создайте новый репозиторий

1. Нажмите зелёную кнопку **New** (или значок «+» → **New repository**)
   в правом верхнем углу GitHub.
2. Укажите имя репозитория, например `barahlo24`.
3. Выберите **Public** (чтобы Actions работали бесплатно) или **Private**.
4. НЕ ставьте галочку «Add a README file» — она не нужна, у нас уже есть
   свой README.
5. Нажмите **Create repository**.

## Шаг 3. Загрузите файлы проекта

Самый простой способ — через браузер, без установки Git:

1. На странице вашего нового (пустого) репозитория найдите ссылку
   **uploading an existing file** (или **Add file → Upload files**).
2. Перетащите в окно браузера **всё содержимое папки `barahlo24/`**
   (project.godot, export_presets.cfg, папки `scenes/`, `scripts/`,
   `data/`, `assets/`, `.github/`, файлы `README.md`, `BUILD.md`,
   `.gitignore`) — именно содержимое, а не саму папку `barahlo24`.
   Структура в репозитории должна выглядеть так, чтобы `project.godot`
   лежал прямо в корне репозитория.
3. Если файлов много и браузер не даёт загрузить всё разом — загружайте
   по частям (например, сначала корневые файлы и `data/`, затем
   `scripts/`, затем `scenes/` и `.github/`).
4. Внизу страницы нажмите **Commit changes**.

> Совет: если вы знакомы с Git, быстрее будет сделать `git clone` вашего
> пустого репозитория, скопировать туда файлы проекта и выполнить
> `git add . && git commit -m "init" && git push`.

## Шаг 4. Запустите сборку

Сборка запускается автоматически при каждом push в ветку `main` или
`master`. Если вы следовали шагу 3, сборка уже должна была запуститься.

Чтобы проверить или запустить вручную:

1. Откройте вкладку **Actions** в вашем репозитории на GitHub.
2. Вы увидите workflow **Build Android APK**. Если он уже выполняется —
   подождите (обычно 5–15 минут на первый прогон, дальше кэш ускоряет
   сборку).
3. Если нужно запустить вручную: нажмите на workflow слева, затем кнопку
   **Run workflow** → **Run workflow**.

## Шаг 5. Скачайте APK

Когда сборка завершится зелёной галочкой ✅:

1. Откройте завершённый запуск workflow (вкладка **Actions** → кликните
   по последнему успешному запуску).
2. Внизу страницы будет раздел **Artifacts** — скачайте файл с именем
   `barahlo24-debug-apk`. Это ZIP-архив, внутри него — сам APK.
3. Либо откройте вкладку **Releases** в репозитории — там тоже будет
   опубликован готовый APK-файл для прямого скачивания.

## Шаг 6. Установите APK на телефон

1. Скачайте `.apk` файл на телефон (через тот же браузер, Google Drive,
   Telegram «Избранное» или USB-кабель — любой удобный способ).
2. На Android перед установкой может потребоваться разрешить установку
   из неизвестных источников:
   - Android 8–9: при открытии файла система сама предложит разрешить
     установку для конкретного приложения (например, для «Файлы» или
     браузера).
   - Android 10+: **Настройки → Приложения → Особый доступ → Установка
     неизвестных приложений** → выберите приложение, из которого
     открываете APK → разрешите.
3. Откройте скачанный `.apk` файл и нажмите **Установить**.
4. После установки иконка «Барахолка24» появится на главном экране.

## Если сборка упала с ошибкой

1. Откройте вкладку **Actions**, кликните на неудачный (красный ❌)
   запуск, откройте шаг с ошибкой.
2. Частые причины:
   - Файлы загружены не в корень репозитория (например, получилась
     вложенная папка `barahlo24/barahlo24/project.godot`). Решение:
     удалите лишний уровень вложенности и перезалейте файлы так, чтобы
     `project.godot` лежал прямо в корне репозитория.
   - `export_presets.cfg` случайно не был загружен или попал в
     `.gitignore` — убедитесь, что этот файл есть в репозитории.
3. После исправления сделайте любой новый commit (например, через
   **Upload files** ещё раз) — сборка запустится заново автоматически.

## Что дальше

- Версия Godot зафиксирована в одном месте: переменная `GODOT_VERSION`
  в файле [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml).
- Собирается **debug-APK** (подписан отладочным ключом, который образ
  `barichello/godot-ci` генерирует сам внутри контейнера). Для публикации
  в Google Play потребуется отдельно настроить release-подпись — это
  осознанно не включено в MVP, чтобы не усложнять сборку новичку.
